## Endpoints (merged to develop)

| Method and path | Roles | Purpose | Task |
| --- | --- | --- | --- |
| `POST /api/v1/auth/login` | Public | Web sign-in; starts a new session | P1-C1 |
| `GET /api/v1/auth/me` | Any signed-in user | The signed-in user's profile | P1-C1 |
| `POST /api/v1/auth/change-password` | Any signed-in user | Changes the password and clears `must_change_password` | P1-C2 |
| `POST /api/v1/auth/logout` | Any signed-in user | Ends the web session | P1-C2 (web part of P1-C4) |

First call `GET /sanctum/csrf-cookie` (framework route, 204) and send the `XSRF-TOKEN` cookie's value as `X-XSRF-TOKEN` on every write.

## Examples

The error bodies were captured from `develop` through the Laravel test client on the MySQL schema database, not from a deployed server. The exception is the "not signed in" text of the 401, which comes from `lang/en/errors.php`. The success examples follow CT-03; the captured responses have the same fields. `id` and names are examples.

### Statuses per endpoint

| Endpoint | Success | Errors |
| --- | --- | --- |
| `POST /auth/login` | 200 | 400 · 401 · 403 · 419 · 422 · 429 |
| `GET /auth/me` | 200 | 401 · 403 |
| `POST /auth/change-password` | 200 | 401 · 403 · 419 · 422 · 429 |
| `POST /auth/logout` | 204, no body | 401 · 403 · 419 |

`403 ACCOUNT_DISABLED` is the only 403 these four endpoints return: `PASSWORD_CHANGE_REQUIRED` applies to other signed-in routes, and none is merged yet.

### POST /api/v1/auth/login → 200

```json
// request
{ "username": "staff.ahmed", "password": "••••••••" }
```

```json
// response
{
  "id": 41,
  "name": "Port Staff",
  "role": "PORT_STAFF",
  "terminal_ids": [],
  "must_change_password": false
}
```

## Known gaps

- **Mobile sign-in:** P1-C3, the mobile part of P1-C4 and P1-C5 (`GET /api/v1/system/info`) are not merged, and their paths are not in the OpenAPI file. CT-04 is approved. Until P1-C3, a Bearer token gets 401.
- **Seed data:** P1-B6 is not merged, so no user per role exists.
- **Dev server:** none until P6-R6 or an earlier host (DEC-47).
- **Web-app origin:** it must be listed in `SANCTUM_STATEFUL_DOMAINS`. Otherwise login answers 400.
- **Password gate:** no route can show `PASSWORD_CHANGE_REQUIRED` until a later endpoint is merged.
- **Frontend review:** the Frontend Team has not reviewed these endpoints (P1-C1, P1-C2).
