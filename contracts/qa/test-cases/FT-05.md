## Detailed Test Cases

### TC-05-001: Terminal Creation with Type and GeoJSON Boundary Polygon
- Description: Verify that a Port Administrator can register a new terminal with code, name, terminal type (CONTAINER or NON_CONTAINER), and boundary polygon coordinates.
- Level: API
- Severity: Blocker
- Governing Contracts: CT-01, CT-02, CT-17 (`terminals`)
- Preconditions: Port Admin authenticated; registered terminals count is below license `max_terminals`.
- Endpoint / Page ID: `POST /api/v1/terminals`
- Steps:
  1. Send `POST /api/v1/terminals` with payload:
     ```json
     {
       "code": "T-CT2",
       "name": "Damietta Container Terminal 2",
       "terminal_type": "CONTAINER",
       "boundary_coordinates": {
         "type": "Polygon",
         "coordinates": [
           [[31.812, 31.425], [31.818, 31.425], [31.818, 31.430], [31.812, 31.430], [31.812, 31.425]]
         ]
       }
     }
     ```
- Expected Result: HTTP 201 Created. Returns created terminal entity with version token and `is_active: true`.
- Evidence: HTTP 201 response payload; record inserted into `terminals` table.
